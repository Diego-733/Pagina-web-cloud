# Sistema de Productos

Proyecto realizado para la asignatura Computación en la Nube.

Permite registrar, ver, modificar y eliminar productos.

## Tecnologías usadas

- HTML
- CSS
- JavaScript
- LocalStorage
- JSON

## Funcionamiento

Los productos tienen:

- ID automático
- Nombre
- Descripción
- Precio

Los datos se guardan en el navegador usando LocalStorage y formato JSON.
